Quick Audit Workflow

  1. Load the site on both desktop and mobile
  2. Run PageSpeed Insights and check for HTTPS
  3. View page source for meta tags and tech stack
  4. Check footer date and blog/news freshness
  5. Try filling out any contact form
  6. Compare the site to 2–3 competitors' sites

Tick items as you go — the more boxes checked, the stronger the case for a remodel.
